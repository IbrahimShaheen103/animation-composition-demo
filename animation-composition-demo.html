Modern CSS · Animation

Old vs New

What happens when an animation changes a transform that already exists?

OLD WAY · DEFAULT REPLACE

Without accumulate

The animation replaces the original transform while it runs.

CSS
.target {
  transform: translateX(50px) rotate(45deg);
  animation: move 2s;
  /* default: replace */
}
NEW WAY · ACCUMULATE

With accumulate

The animation is combined with the original transform.

CSS
.target {
  transform: translateX(50px) rotate(45deg);
  animation: move 2s;
  animation-composition: accumulate;
}

Watch both boxes at the same time. The animation runs for 2 seconds.
